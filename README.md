# Arabic Client

مود Fabric لماين كرافت **1.21.1** بهوية عربية بالكامل (v0.3.0). الناتج النهائي
مود عادي بصيغة **.jar** زي أي مود Fabric تاني، بيتحط في فولدر `mods`.

## الميزات الحالية

### 🏠 شاشة رئيسية مخصصة (Main Menu)
تصميم كامل يستبدل شاشة ماين كرافت الافتراضية بالكامل:
- خلفية متدرجة أسود ↦ عنّابي غامق، مع نقشة معينات هندسية ذهبية خفيفة (زخرفة عربية، مرسومة بالكود من غير أي صورة خارجية).
- شعارك (الطربوش) في النص + اسم "Arabic Client" بالذهبي + سطر تعريفي.
- أزرار: اللعب المنفرد، متعدد اللاعبين، Arabic Client (يفتح منيو المود)، الإعدادات العامة، خروج.
- شريط سفلي بيوضح رقم إصدار المود ونسخة ماين كرافت.

### 🖥️ منيو موحّد داخل اللعبة (زرار `K`)
منيو بتابات: الأداء / Keystrokes / الشارة / عن المود ("حوار الأيقونة": شعارك بحجم كبير + رقم الإصدار).

### ⚡ تحسين الأداء (FPS Boost)
- إلغاء رسم الغيوم، تقليل الجسيمات، تقليل مسافة رؤية الكيانات، رسومات سريعة.
- بيرجّع الإعدادات الأصلية زي ما كانت لما تلغي الوضع، وبيتحفظ تلقائيًا.

### ⌨️ Keystrokes Overlay
- صندوق W/A/S/D + زرار الماوس الشمال (LMB) واليمين (RMB) + عداد **CPS** لحظي.

### 🏷️ شارة الاسم (Tab list + F3)
- شارة (أيقونتك) بتظهر جنب اسمك في **Tab list** تلقائيًا، وسطر "Arabic Client vX.X.X" في **F3**.
- لظهورها عند لاعبين تانيين عندهم نفس المود، تحط رابط JSON بسيط (Array من UUIDs)
  في تاب "الشارة" (اشرحها بالتفصيل تحت في قسم "الشارة لغيرك").

## إيه اللي جاي بعد كده

- تخصيص موضع/حجم الـ Keystrokes overlay بالسحب داخل اللعبة.
- تحسينات أداء إضافية (chunk building, entity culling متقدم، إلخ).

## متطلبات البناء

- **JDK 21** (لازم يكون مظبوط في `JAVA_HOME` أو متاح لـ Gradle).
- اتصال إنترنت عادي (Gradle هيحمّل Minecraft + Yarn mappings + Fabric Loader + Fabric API تلقائيًا أول مرة).
- IntelliJ IDEA (موصى بيه) أو أي IDE بيدعم Gradle.

## خطوات البناء والتشغيل

```bash
# 1. من جوه فولدر المشروع
cd arabic-client

# 2. (اختياري لكن موصى بيه) شغّل الأمر ده الأول للتأكد إن كل حاجة بتتحمل صح
./gradlew --version

# 3. ابني المود
./gradlew build

# الملف الناتج هيكون في:
# build/libs/arabic-client-0.1.0.jar
```

للتجربة المباشرة من غير ما تعمل build/نقل الملف يدويًا:

```bash
./gradlew runClient
```

الأمر ده هيفتح نسخة Minecraft فيها المود شغال تلقائيًا (Fabric Loom بيظبط كل حاجة).

## التثبيت في لانشر عادي (بعد البناء)

1. حمّل [Fabric Loader](https://fabricmc.net/use/) لإصدار 1.21.1.
2. حمّل [Fabric API](https://modrinth.com/mod/fabric-api) لنفس الإصدار وحطه في فولدر `mods`.
3. انسخ `build/libs/arabic-client-0.1.0.jar` (مش النسخة اللي فيها `-sources`) لنفس فولدر `mods`.
4. شغّل اللعبة باختيار Fabric profile.

## ملاحظة مهمة عن الكود

الكود ده اتكتب يدويًا بالاعتماد على Yarn mappings لإصدار 1.21.1، لكن معملتش build فعلي ليه لأن بيئة التطوير اللي كتبته فيها معندهاش وصول لسيرفرات Minecraft/Fabric (maven.fabricmc.net). يعني ممكن تقابل **error بسيط في اسم method أو field واحد** (زي `getCloudRenderMode` أو `getEntityDistanceScaling`) لو الـ mappings الدقيقة مختلفة شوية عن اللي افترضتها.

لو حصل كده:
1. افتح المشروع في IntelliJ واعمل Gradle sync.
2. دوس Ctrl+Click (أو Cmd+Click) على الكلاس `GameOptions` جوه `PerformanceManager.java`.
3. دور على الـ method القريبة من الاسم اللي مكتوب (هتلاقيها غالبًا نفس المعنى بفرق بسيط في الاسم).
4. صحح الاسم واعمل build تاني.

قولّي لو واجهتك أي error وهساعدك تصلحها فورًا.

## الشارة لغيرك (Badge لغير نفسك)

المود مبيعرفش تلقائيًا مين اللاعبين التانيين اللي عندهم نفس المود من غير سيرفر
backend حقيقي. الحل البسيط والصادق هنا: تحط رابط JSON بسيط (Array من UUIDs
بدون شرطات) في تاب "الشارة"، وأي حد الـ UUID بتاعه موجود في القايمة هتظهرله
الشارة عند أي حد تاني عنده المود. تقدر تستضيف الملف ده مجانًا على GitHub
(raw.githubusercontent.com) وتحدّثه وقت ما تحب، مثال لشكل الملف:

```json
["069a79f444e94726a5befca90e38aaf5", "..."]
```
